FIREBASE BACKEND

Multiplayer runs on your Firebase project. This build ships with the keystorm-123 config baked in — paste a different firebaseConfig below to override it (stored in localStorage). Google sign-in needs this page served over http(s) with the domain in Authentication → Authorized domains.

SECURITY RULES + CHECKLIST (paste into Firebase console) 
1) AUTHENTICATION → Sign-in method → enable Google
2) AUTHENTICATION → Settings → Authorized domains → add the
   host you serve this page from (localhost is pre-authorized)

3) REALTIME DATABASE → Rules:
{
  "rules": {
    "rooms": {
      "$code": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}

4) FIRESTORE DATABASE → Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /leaderboard/{uid} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
                   && request.auth.uid == uid;
    }
    match /history/{id} {
      allow read, write: if request.auth != null;
    }
  }
}

5) Create a Firestore database if you haven't yet (leaderboard +
   history live there). Rooms live in Realtime DB.
NOTE: anti-cheat heuristics are client-side. Add App Check +
Cloud Functions before going fully public.
